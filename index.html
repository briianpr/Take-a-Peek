FAQ

Pertanyaan umum.

Apakah demo di atas benar-benar berjalan?

Ya. Demo berjalan otomatis menggunakan HTML, CSS, dan JavaScript. Tidak membutuhkan video eksternal.

Apakah bisa dipasang di GitHub Pages?

Bisa. Semua aset ada di dalam folder proyek dan tidak membutuhkan proses build.

Apakah bisa dibuka fullscreen?

Bisa. Tekan tombol Fullscreen pada bagian demo atau buka URL website dengan parameter ?demo=1.
